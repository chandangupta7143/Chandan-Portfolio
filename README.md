# 🚀 Chandan Gupta – Developer Portfolio

This is my personal portfolio website built using **React + Vite**, designed to showcase my skills, projects, and journey as a **Java Full Stack Developer**.

The portfolio focuses on clean UI, smooth animations, and modern frontend practices.

---

## 🛠️ Tech Stack

- ⚛️ React.js  
- ⚡ Vite  
- 🎨 Tailwind CSS  
- 🎞️ Framer Motion  
- 🧠 JavaScript (ES6+)  
- 📱 Responsive Design  

---

## ✨ Features

- Modern & minimal UI  
- Smooth animations using Framer Motion  
- Fully responsive across all devices  
- Fast performance with Vite & HMR  
- Reusable and scalable React components  
- Sections: About, Skills, Projects, Contact
